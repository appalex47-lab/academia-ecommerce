FUNCIONALIDADES IMPLEMENTADAS
1. Cadena de pensamiento analítico:
   Dato/observar → cuantificar → comparar → interpretar → segmentar → diagnosticar →
   formular hipótesis → recomendar → medir.
2. Cada ejercicio existente puede declarar las etapas analíticas que practica.
3. La actividad queda integrada con el estado de intentos y con la evidencia de Fase 5.
4. El bloque PIENSA COMO ANALISTA se amplió para conectar reflexión con la siguiente
   pregunta analítica, sin convertirse en teoría extensa.
5. Las actividades cualitativas de L5-L8 incorporan rúbricas explícitas y determinísticas.
   El alumno marca criterios que considera cumplidos; no se interpreta automáticamente
   el texto libre.
6. La evidencia acumulada conserva también las etapas analíticas practicadas y los
   criterios explícitos marcados.
7. La persistencia continúa usando la misma clave de Fase 2:
   cursoAnalista.fase2.progress.v1

MODELO DE RAZONAMIENTO
- L1: observar/cuantificar y comparación inicial.
- L2: cuantificar → comparar → interpretar.
- L3: observar → cuantificar → comparar → interpretar.
- L4: cuantificar → comparar → interpretar → segmentar.
- L5: observar → comparar → segmentar → diagnosticar → hipotetizar → medir.
- L6: observar → cuantificar → segmentar → diagnosticar → hipotetizar → recomendar → medir.
- L7: cuantificar → comparar → interpretar → segmentar → hipotetizar → medir.
- L8: recorre la cadena completa como aplicación integradora.

RESPUESTAS CUALITATIVAS
- No se usa IA, LLM ni NLP.
- No se infiere significado semántico del texto libre.
- Las rúbricas son criterios explícitos y visibles para el alumno.
- Marcar criterios registra evidencia pedagógica, no una calificación.

INTEGRACIÓN CON FASES 1-5
- Fase 1: reutiliza conceptos, tipos y niveles cognitivos.
- Fase 2: cada intento, pista y solución continúa formando parte del estado existente.
- Fase 3: los errores permanecen en errorHistory y alimentan la evidencia.
- Fase 4: la cadena analítica se muestra dentro de la progresión pedagógica.
- Fase 5: las etapas analíticas y criterios se agregan a la evidencia por concepto/nivel.
