MODELO DE ESTADO
----------------
Cada ejercicio puede conservar:

attempts
attemptResults[]
hintsUsed
revealedHints[]
firstAttemptCorrect
completed
solvedCorrectly
solutionViewed

Reglas principales:
- Solo enviar una respuesta incrementa attempts.
- Una pista nunca incrementa attempts.
- Una misma pista solo cuenta una vez.
- firstAttemptCorrect se establece únicamente con el primer intento.
- completed y solvedCorrectly solo son verdaderos después de una resolución.
- solutionViewed es independiente de completed.
- Ver la solución no convierte el ejercicio en correcto.

FLUJO NUEVO
-----------
RETO
  ↓
INTENTO
  ↓
¿CORRECTO?
  ├─ Sí → explicación/aplicación → completado
  └─ No → feedback → pista → nuevo intento
                         ↓
                    más pistas
                         ↓
                  solución controlada

Cuando ya no hay pistas y el ejercicio sigue fallando, se ofrece revisar la
solución. El alumno no queda bloqueado indefinidamente.

EJERCICIOS CUALITATIVOS
-----------------------
No se intenta evaluar automáticamente lenguaje natural.

El flujo es:
respuesta → intento registrado → pistas/solución → autoevaluación explícita.

La autoevaluación no crea un intento artificial y mantiene separado el hecho
de haber revisado la solución del hecho de haber marcado el ejercicio como
resuelto.

PERSISTENCIA
------------
La auditoría de Fase 0 no encontró persistencia de progreso existente.
Por ello, para no crear dos mecanismos paralelos, Fase 2 incorpora un único
almacenamiento local con la clave:

cursoAnalista.fase2.progress.v1

Se persisten:
- índice de lección;
- lessonStatus;
- estado de cada ejercicio;
- intentos y resultados;
- pistas utilizadas;
- firstAttemptCorrect;
- completed;
- solvedCorrectly;
- solutionViewed.

La carga defensiva normaliza datos corruptos o incompletos y evita estados
como completed=true sin solvedCorrectly=true.

REGRESIONES ENCONTRADAS Y CORREGIDAS
-------------------------------------
- Durante la integración se detectó que loadLearningState devolvía el estado
  inicial antes de asignarlo al estado global cuando no existía almacenamiento.
  Fue corregido para inicializar explícitamente lessonStatus y
  exerciseLearningState.
- El test de regresión original de Fase 1 asumía que los ejercicios
  cualitativos se completaban al pulsar directamente "Ver solución". Ese
  comportamiento ya no es compatible con Fase 2, por lo que el test fue
  actualizado para validar el nuevo flujo: respuesta → revisión →
  autoevaluación.
