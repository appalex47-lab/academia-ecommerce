FASE 1 — MODELO PEDAGÓGICO Y ESTRUCTURA DE APRENDIZAJE
Curso Autodidacta de Analista

ALCANCE
Se implementó exclusivamente la Fase 1 solicitada: extensión del modelo de ejercicios para soportar conceptos, nivel cognitivo, dificultad, tipo y metadata futura, manteniendo compatibilidad con el motor existente.

FUENTES DE IMPLEMENTACIÓN
La aplicación original fue entregada como exportaciones PDF de HTML, CSS y JavaScript. El script.js e index.html de esta entrega se reconstruyeron a partir de esos archivos, preservando el comportamiento existente y aplicando únicamente los cambios de Fase 1.

ANTES
- lessons contenía IDs de ejercicios.
- exerciseStatus guardaba únicamente booleanos.
- Las reglas de validación estaban dentro de checkL1(), checkL1Reto(), etc.
- No existía un catálogo pedagógico central.
- No existía una normalización de ejercicios legacy.

DESPUÉS
- Se mantienen intactos los IDs de lessons y ejercicios.
- Se agregaron COGNITIVE_LEVELS y EXERCISE_TYPES.
- Se agregó un catálogo central concepts.
- Se agregó exerciseMetadata para los 10 ejercicios actuales.
- Se agregó normalizeExercise(exercise), compatible con IDs legacy y objetos parciales.
- Se agregó getExercise() y getLessonExercises() para acceder al modelo enriquecido sin cambiar el contrato actual.
- Se prepararon campos opcionales: hints, analystThinking, rubric, errorPatterns y tags.
- Se agregó un ejercicio técnico aislado de prueba de la nueva estructura; no entra en el flujo del alumno.
- Se agregó validatePedagogicalModel() como comprobación estructural de desarrollo.

COMPATIBILIDAD
- Los ejercicios actuales continúan usando sus IDs originales.
- Las funciones de validación existentes conservan sus cifras y tolerancias.
- lessonStatus y exerciseStatus conservan su contrato actual.
- La navegación anterior/siguiente conserva su lógica.
- Los ejercicios cualitativos L5-L8 conservan su comportamiento actual.
- Un ejercicio legacy sin metadata puede pasar por normalizeExercise() y recibe defaults null/[] sin romper el motor.

CAMBIO UI MÍNIMO
Se corrigió únicamente el contador estático inicial del HTML de 0/7 a 0/10, porque el curso contiene 10 ejercicios y el panel dinámico ya calcula ese total.
No se rediseñó la interfaz ni se modificó la navegación, modal, dashboard o experiencia visual.
